# V101 İadeler Görsel Düzeltmesi

- İadeler / İptaller tablolarında ürün görselleri görünür hale getirildi.
- Tablo artık yalnızca `line.image` alanına bağlı kalmıyor.
- `resolveOrderImage(line)` ile ürün kataloğundaki eşleşen görsel de kullanılabiliyor.
- Görseller büyütme için tıklanabilir yapıldı.
